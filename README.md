## Описание
  В данном проекте я реализовал подобный пример, когда исходные данные заполняются человеком вручную в табличном файле, далее отдаются системе на обработку и сбор статистических данных, а затем оформляются в требуемые форматы и кладутся в подготовленные директории, чтобы сторонние системы смогли забрать эту статистику себе и каким-либо образом продолжить использование этих данных. Так как системы бывают разные и не всегда можно на них влиять (например, система давно написана кем-то сторонним и не поддерживается), могут требоваться разные представления одних и тех же данных. Поэтому генерируют файлы JSON и XML, а также Excel-файл для возвращения пользователям обработанных данных.
  Проект был создан в рамках практики Backend-разработки на Java.

## Функциональность
  - Получение данных из файлов Excel
  - Различные варианты сортировки данных
  - Сериализация объектов и коллекций объектов в JSON
  - Создание и заполнение нового файла Excel

## Технологии

  | Технология | Назначение |
| ----------- | ----------- |
| Java 17    | основной язык  |
| Apache POI   | работа с файлами  |
| Stream API    | сортировка  |
| Goole Gson   | сериализацией/десериализацией   |
| Logger    | логирование   |
| Maven    | система сборки   |

## Установка
### Клонировать репозиторий
```
git clone https://github.com/DmitryLkT/University_Project.git
```
### Перейти в директорию
```
cd University_Project
```
### Собрать и запустить

```
mvn exec:java -Dexec.mainClass="org.LukDT.main"
```
